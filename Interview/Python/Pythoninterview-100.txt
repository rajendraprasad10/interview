How is memory managed in Python?

	Memory management in Python is handled automatically by the Python memory manager. It is responsible for allocating and deallocating memory to objects during the program's execution. Here’s an overview of how memory is managed in Python:
	
	1. Memory Allocation
Python divides memory into private heap space and manages it using the Python memory manager.
	Private Heap: All Python objects and data structures are stored in the private heap. This heap is not accessible directly to the programmer.
	Built-in Allocators: Python provides built-in methods such as malloc, calloc, and realloc for memory allocation within the heap.
	
	2. Garbage Collection
Python automatically manages memory through a built-in garbage collector to reclaim memory from objects that are no longer in use.

	Reference Counting:
Python keeps track of the number of references to each object.
When an object’s reference count drops to zero, it is eligible for garbage collection.

	Cyclic Garbage Collection:
Python can detect and clean up cycles of objects that reference each other, even if their reference count is not zero.
Cycles are handled using the garbage collector (gc module).

	3. Dynamic Typing
Python variables are dynamically typed, meaning the type of an object is determined at runtime. The memory for objects is allocated dynamically based on their type.

What is the difference between deepcopy and copy?

Answer:

copy.copy() creates a shallow copy, while copy.deepcopy() creates a deep copy.

Example:

python
Copy
Edit
import copy
list1 = [[1, 2], [3, 4]]
shallow = copy.copy(list1)
deep = copy.deepcopy(list1)
list1[0][0] = 99
print(shallow)  # [[99, 2], [3, 4]]
print(deep)     # [[1, 2], [3, 4]]
What is a Python decorator?

Answer: A decorator is a function that modifies the behavior of another function.

Example:

python
Copy
Edit
def my_decorator(func):
    def wrapper():
        print("Before the function call")
        func()
        print("After the function call")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")
say_hello()
Explain the Global Interpreter Lock (GIL).

Answer: The GIL is a mutex that protects access to Python objects, ensuring only one thread executes Python bytecode at a time. It affects multi-threaded Python programs but can be bypassed using multiprocessing.

OOP Concepts in Python
What is the difference between @staticmethod and @classmethod?

Answer:

@staticmethod: Does not access or modify class or instance data.

@classmethod: Takes the class as its first argument (cls), can modify the class state.

Example:

python
Copy
Edit
class MyClass:
    @staticmethod
    def static_method():
        print("Static method called")

    @classmethod
    def class_method(cls):
        print(f"Class method called from {cls.__name__}")

MyClass.static_method()
MyClass.class_method()
What are metaclasses in Python?

Answer: Metaclasses define the behavior of a class. They are classes for classes.

Example:

python
Copy
Edit
class Meta(type):
    def __new__(cls, name, bases, dct):
        dct['greet'] = lambda self: print("Hello from", name)
        return super().__new__(cls, name, bases, dct)

class MyClass(metaclass=Meta):
    pass

obj = MyClass()
obj.greet()
